# Keyboard, display and accessibility

On desktop, Ctrl+1 through Ctrl+5 switch sections. F1 opens shortcut help.
Tab and Shift+Tab follow the visual focus order, Enter/Space activate focused
controls, and Escape closes dialogs. During quizzes, number keys select answers,
Enter advances, and arrow keys move between questions. During flashcard study,
Space flips and 1–4 grade the revealed answer. Grading is blocked while saving.

Wide quiz libraries and catalogs show list/detail panes. Windows enforces an
800×600 logical minimum window size, adjusted for display DPI. Smaller devices
use one pane and bottom navigation. Content scrolls and action groups wrap.

Settings offers system, light and dark modes. Charts use the current Material
color scheme. Correct/incorrect results include check/cross symbols and spoken
labels; status is never conveyed by color alone. Flashcards announce their side,
flip action, and session progress. Text uses the system text scaler, including
rich answer labels and long flashcards, tested up to 200%.

Automated accessibility checks cover labeled controls, large text and both
brightness modes. Native screen-reader behavior and Windows DPI resizing still
need hands-on verification on each release platform.
